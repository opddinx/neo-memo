# v1の境界・既知の制約

この資料は未実装機能を仕様済み機能と混同しないための実装状態メモです。

## 配布・検証

ソースコードの配布です。署名済みアプリ、Windows installer、macOS DMGは含みません。Electronはnpmから取得する指定で、本環境では外部ネットワーク制約により取得・実行できませんでした。Chromium上のGUIと実Nodeコア・Gitを結合して検証していますが、Electron本体・IPC・OS鍵ストア・各OS上のダイアログや配布挙動の検証ではありません。

外部サービスは公式仕様を確認してadapterを実装し、fixtureで検証しました。自分の実アカウントのトークンを使ったSlack / Discord / X / OpenAIへの接続は未検証です。GUI起動時、Electronダウンロードと実サービス設定に関する初回確認が必要です。

## 運用

PCの本体GUIはオフラインでも読み書きできます。スマホは既存Slack / Discord経由の入力に限定します。アプリが終了している間は取得しません。起動・ネットワークonlineイベントの検知で取り込みますが、OSのスリープ復帰が必ずそのイベントを発行するとは保証しないため、「取り込む」ボタンを併用してください。

複数PC間での自動競合解決はしません。主端末1台を基本とし、Gitが分岐したら停止します。保存した画像はGitの履歴に蓄積します。Gitから消す必要がある機密情報について、通常のファイル削除だけで履歴まで消えるわけではありません。remote同期なしのローカルGitはPC故障への対策になりません。

## 入力・取得

Slackのトップレベル投稿と、指定したDiscordテキストチャンネルが対象です。取り込み済み投稿の後日の編集・削除、スレッド返信、フォーラム配下のスレッド走査、ファイルだけの投稿は追跡しません。Slack転送メッセージ等で本文URLがネストされた特殊フィールドにしか入らない場合も取り込めません。通常投稿としてURLを貼る運用を使ってください。

Slack無料枠の履歴制限に到達したデータは取り込めません。Discord本文が空の場合にチェックポイントを進めない検査は保守的なので、特殊な空メッセージでも停止することがあります。

一般Web / noteはHTMLのメタデータのみです。本文全体、JavaScriptで生成される内容、PDF本文、ログイン先、記事画像一式、動画は取り込みません。文字コードはUTF-8を前提とします。robots判定は通常のUser-agent / Allow / Disallow / ワイルドカード等を扱いますが、RFCの全エッジケースに適合確認済みの汎用クローラーではありません。

URLは既知の追跡パラメータのみを除去します。短縮URLと転送先、canonical指定だけが同じページ、意味のあるfragmentの違いは別カードになる場合があります。誤統合を避けるための保守的な判定です。

v1のX認証は取得済みOAuth user access tokenの手動入力です。トークン取得用ログイン画面や自動更新はありません。ブックマークの最古までの取得可能性はAPI側に依存します。全ページ読み終えた後の次回取得は先頭からになります。既知データでもAPI呼び出し料金は別途発生し得ます。取得済み投稿の削除状態を自動照合する仕組みはありません。X API等の利用条件に適合する運用は別途確認してください。

## GUI・検索・AI

画像は1カード1プレビュー。GUIはElectron基盤なので、実行バイナリや常駐メモリが特に小さい設計ではありません。ここでいう軽量は操作と運用の単純さです。

検索は日本語を含む部分一致・複数語ANDです。意味検索ではありません。ファイルを毎回読み直す方式で、数万件・数十万件に対する性能は未測定です。GUIは120件単位で表示を増やします。

AIは任意の外部処理です。モデルによってstructured outputへの対応やトークン制限が異なり、安価なモデルでも正確な分類が保証されるわけではありません。`store:false` はゼロ保持契約を意味しません。送信を有効にした場合の情報の扱いはAPI提供者の条件を確認してください。

MCP server / 内蔵チャットはありません。外部LLMからはファイルまたはCLI JSON検索を使う接続点を提供します。記述済みのMarkdownはJSON形式frontmatterを使います。任意のYAMLへの書き換えはパーサーが受け付けません。
